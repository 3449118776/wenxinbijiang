## 二、平台节奏模板

### 模板 1：番茄·爽文流
**标签**：快节奏、强钩子、高密度爽点

**整体强度**：⭐⭐⭐⭐⭐（5/5）

**前3章（黄金三章）**
- 第1章：铺垫（介绍处境）→ 触发事件 → 大爆点（初显身手）→ 钩子
- 第2章：小爆点（打脸/反击）→ 铺垫 → 钩子
- 第3章：中爆点（重要进展）→ 伏笔埋设 → 大钩子

**常规章节节奏**
- 每3章：一个小爆点
- 每5章：一个中爆点
- 每7章：一个伏笔埋设
- 每8章：一次人设补全
- 每10章：一个大爆点
- 每章必有：章尾钩子

**适用题材**：都市异能、系统流、无敌流、玄幻爽文

---

### 模板 2：起点·慢热流
**标签**：慢热、厚重、世界观宏大

**整体强度**：⭐⭐⭐（3/5）

**前期（1-10章）**
- 世界观展开占比高（30%）
- 节奏偏缓，重在铺垫和引入
- 第5章左右第一个小爆点
- 第10章左右第一个中爆点

**中期（11-30章）**
- 节奏逐步加快
- 每5章一中爆点
- 每10章一大爆点
- 人设补全和世界观展开穿插

**后期（30章+）**
- 进入主线高潮
- 大爆点密度提升
- 伏笔回收频繁

**适用题材**：史诗奇幻、古典仙侠、历史军事

---

### 模板 3：晋江·情感流
**标签**：细腻、情感驱动、人物成长

**整体强度**：⭐⭐（2.5/5）

**节奏特点**
- 情感节拍占比高（30%+）
- 剧情线服务于感情线
- 心理描写细腻
- 人物弧光清晰

**情感节点规划**
- 第3-5章：初遇/重逢
- 第10章左右：心动瞬间
- 第15章左右：第一个误会/冲突
- 第20章左右：关系突破
- 第25章左右：重大危机
- 第30章左右：和解/告白

**适用题材**：现代言情、古代言情、青春校园

---

### 模板 4：悬疑·解谜流
**标签**：悬念迭起、逻辑严密、反转不断

**整体强度**：⭐⭐⭐⭐（4/5）

**节奏特点**
- 每章都有新线索/新疑问
- 伏笔密度高
- 反转频率高
- 真相揭示冲击力强

**关键节点**
- 第1章：案件/谜团出现 → 钩子
- 每3-5章：一个重要线索
- 每10章：一个小反转
- 每20章：一个大反转
- 结局：终极真相揭示

**适用题材**：悬疑推理、灵异恐怖、规则怪谈

---

### 模板 5：经营·建设流
**标签**：逐步成长、积累感、成就感

**整体强度**：⭐⭐⭐（3/5）

**节奏特点**
- 阶段性成果明显
- 数值/规模增长可视化
- 危机-解决-升级循环
- 势力/领地逐步扩张

**发展阶段**
- 初期（1-20章）：白手起家 → 第一桶金 → 初步立足
- 中期（21-50章）：快速扩张 → 势力成型 → 第一次大危机
- 后期（50章+）：格局争霸 → 终极对决 → 登顶/归隐

**适用题材**：种田经营、基建发展、领主争霸、游戏异界

## 三、节奏调整指南

### 节奏拖沓怎么办？

**症状**：读者觉得"水"、看不下去、想跳章

**调整策略**：
1. 压缩环境描写，保留最核心的1-2个细节
2. 增加动作和冲突，让人物"动"起来
3. 拆分长段落，每段不超过3-4行
4. 减少心理独白，用行动和对话展现内心
5. 每章至少推进1个剧情节点
6. 章尾加钩子

### 节奏太快怎么办？

**症状**：读者跟不上、没代入感、情绪没积累

**调整策略**：
1. 增加关键场景的细节描写
2. 放慢情绪积累的过程
3. 增加人物反应和心理活动
4. 补充过渡章节，让转折更自然
5. 增加感官细节，让场景更立体

### 全是对话怎么办？

**症状**：像剧本、没有画面感、人物像在"报台词"

**调整策略**：
1. 每段对话之间插入动作描写
2. 增加环境和氛围描写
3. 描写人物说话时的表情、动作、语气
4. 适当加入心理活动
5. 用叙述代替不重要的对话

### 全是叙述怎么办？

**症状**：像大纲、干巴巴、没有代入感

**调整策略**：
1. 把叙述转化为场景和对话
2. 让人物"演"出来，而不是作者"说"出来
3. 增加具体的细节和例子
4. 用人物的视角来展现
5. 适当加入对话和互动

## 四、章节内节奏模板

### 开篇节奏（前300字）
**目标**：抓住读者，建立期待

**推荐结构**：
1. 动作/对话/冲突开头（不要环境描写开头）
2. 快速建立人物处境
3. 抛出第一个小悬念/冲突
4. 引导读者继续往下看

### 中段节奏
**目标**：推进剧情，积累情绪

**推荐结构**：
1. 承接开篇的冲突/悬念
2. 逐步升级，2-3个小起伏
3. 插入人设/世界观细节
4. 为结尾高潮做铺垫

### 结尾节奏（最后100-200字）
**目标**：留下钩子，让读者想看下一章

**推荐结构**：
1. 本章事件的余波
2. 新的悬念/转折/意外出现
3. 在最高潮/最紧张处戛然而止
4. 不要把事情说满，留一半
