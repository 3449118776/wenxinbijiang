# 网文黄金三章模板

## 一、通用三章任务清单

### 第一章
- [ ] 前300字：冲突/反常/强烈情绪开头（不是环境描写！）
- [ ] 前500字：主角出场，展现一个可被感知的特征
- [ ] 前1500字：至少1个微型爽点或信息钩子
- [ ] 前1500字：建立读者对主角的初步情绪（同情/认同/好奇）
- [ ] 章尾：有明确的钩子（悬念/转折/提问）

### 第二章
- [ ] 初步展现核心能力/金手指
- [ ] 让读者知道这本书"卖什么"
- [ ] 建立期待方向（后续看什么）
- [ ] 避免：第一次打斗/冲突拖太长

### 第三章
- [ ] 完成第一个完整剧情单元
- [ ] 第一个小冲突有结果（赢/输/平都行）
- [ ] 抛出全书级的核心悬念或目标
- [ ] 强钩子结尾，驱动读者点开第四章

---

## 二、番茄模板（最快切入型）

每章约 2000-2500 字

### 第1章（2000字）
```
前200字：主角面临危机（退婚/被甩/濒死/失业）
200-800字：危机加剧 or 爆发冲突
800-1500字：触发金手指（系统/重生/捡宝/穿越）
1500-2000字：金手指效果初现 + 章尾悬念
钩子：接下来会发生什么？
```

### 第2章（2500字）
```
前800字：金手指实战（打脸/碾压/获得好处）
800-1500字：展示新能力带来的变化
1500-2000字：新的冲突或对手出现
2000-2500字：主角做出第一次主动决策
钩子：展开中的威胁
```

### 第3章（2500字）
```
前500字：第一个冲突的收尾
500-1500字：解锁系统核心功能/新地图/新目标
1500-2000字：建立中期目标（升级、复仇、寻宝）
2000-2500字：更大的幕后人/势力浮现
钩子：全书级悬念
```

## 三、起点模板（铺垫型，但要有动作）

每章约 3000 字

### 第1章（3000字）
```
前500字：一个有张力的场景切入（不一定是战斗）
500-1500字：主角身份和生活状态的展示
1500-2500字：触发核心设定（穿越/觉醒/奇遇）
2500-3000字：主角对变化的反应 + 章尾钩子
钩子：这个变化会带来什么？
```

### 第2-3章（每章3000字）
```
主角开始适应和探索金手指/新能力
世界观初步展开（不要一次性倒设定）
结识第一个重要配角
遭遇第一个真正的冲突（不是口头吵架，是有后果的）
章尾钩子：冲突的结果悬而未决
```

---

## 四、晋江模板（情感优先型）

每章约 2500 字

### 第1章（2500字）
```
前300字：主角的情绪高光时刻（可以是负面的：崩溃/绝望/愤怒）
300-1000字：展示主角的困境和内心戏（让读者共情）
1000-1800字：核心设定触发（穿越/重生/偶遇关键人物）
1800-2500字：与关键人物的第一次互动
钩子：这次的相遇会改变什么？
```

### 第2-3章
```
情感线开始铺设（不要一上来就发糖）
通过细节展现人物的性格和潜在关系
埋下后续矛盾的种子
章尾钩子：情感层面的悬念（他到底怎么想的？）
```

---

## 五、黄金三章自检清单

- [ ] 第一段就有冲突或反常（无环境描写开头）
- [ ] 主角在前500字内出场
- [ ] 第一章内有至少1个微型爽点或信息钩子
- [ ] 章尾有明确的钩子（不是日常对话结尾）
- [ ] 第二章结束了第一个战斗/冲突/事件（不是拖到第三章）
- [ ] 第三章内完成了第一个完整剧情单元
- [ ] 第三章结尾抛出了全书级悬念
- [ ] 前三章的"卖点"是清晰的——读者知道这本书是什么类型
- [ ] 没有在第一、第二章大段倒设定
- [ ] 番茄文：每章≥1个爽点 / 起点文：三章内累计≥2个爽点
